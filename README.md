# RESONANT

Personal Music Intelligence System.

## Stack
- Next.js 15 + React 19 + TypeScript + Tailwind
- Genre × Mood engine, Taste DNA, Session Brain, Discovery Depth
- Multi-provider (MusicBrainz, Discogs, internal catalog)

## Scripts
```bash
npm install
npm run typecheck
npm run lint
npm test
npm run build
npm run test:e2e
npm run dev
```

## Deploy
```bash
npx vercel --prod
```
